En kort introduktion

Så fungerar Claude Code

Claude Code är en AI-assistent som arbetar direkt på din dator. Den läser dina filer, kör kommandon och gör ändringar, och du godkänner varje steg.

Vad är det?

En vanlig chatt-AI kan bara svara med text. Claude Code kan dessutom agera: öppna och redigera filer, söka i en mapp, köra program och använda verktyg som Git. Du beskriver vad du vill göra på vanlig svenska, och Claude tar fram en plan och utför den.

Så går det till

  1. Du beskriver uppgiftenTill exempel: ”Gör en enkel hemsida om Claude Code och publicera den på GitHub.”
  2. Claude undersökerDen tittar på filerna i mappen och kontrollerar vilka verktyg som finns installerade.
  3. Claude gör en planUppgiften delas upp i steg som du kan följa medan arbetet pågår.
  4. Claude utför stegenDen skriver filer och kör kommandon. Det som är känsligt eller svårt att ångra godkänner du först.
  5. Du granskar resultatetClaude berättar vad som har gjorts och vad som återstår, och du kan be om ändringar.

Vad kan man använda det till?

Programmering

Skriva, förklara och felsöka kod i alla vanliga språk.

Dokument

Sammanfatta, strukturera och skriva texter utifrån dina filer.

Automatisering

Byta namn på filer, sortera mappar och upprepa tråkiga uppgifter.

Webb

Bygga hemsidor och publicera dem, precis som den här.

Var finns det?

Claude Code finns i terminalen, som skrivbordsapp för Mac och Windows, på webben och som tillägg till kodredigerare som VS Code. I terminalen startar du det med kommandot:

claude

Tips för att komma igång

Var tydlig

Berätta vad målet är, inte bara vilket steg du vill ha.

Börja smått

Testa på en liten uppgift i en egen mapp först.

Läs planen

Följ stegen och säg till om något går åt fel håll.
